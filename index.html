Data & methodology

  • Source: eth_getLogs on the StoaRouter contract 0x2F28…3eE5, event Routed(address,address,address,address,address,uint256,uint256,address,address,address) (topic0 0x2bbc…f6da), in 1,000,000-block chunks. First Routed event: block 114,378,637 (2026-11-14 19:00:34 UTC). Block time ≈ 0.104 s.
  • RPC: https://rpc.mainnet.chain.robinhood.com (fallback https://robinhood.drpc.org). Both send Access-Control-Allow-Origin: *, so the page reads the chain directly from your browser — no server, no key.
  • USD volume: a swap's USD value comes from its USDG leg (USDG = $1) when present, otherwise its ETH leg × the live CoinGecko ETH price. Swaps with neither leg (e.g. STOA ↔ SPCX) have no USD value and are excluded from USD totals — shown in native amounts only.
  • Tokens: symbols/decimals resolved on-chain via symbol()/decimals() (verified 2026-11-21). Two different tokens both call themselves “STOA” (0x13e6… is the official $STOA; 0x1dd5… is a separate token) — the dashboard disambiguates them by address.
  • Venues: names from Stoa's official contracts page (Uniswap V3, Uniswap V4, Uniswap V4 V2, Aero, Ramses, Pons Curve, Uniswap V2, Metric). Unknown venues show a truncated address — never a guessed name.
  • Referrer: every swap the dashboard's quote box prepares names 0x4e1460e9b71686c7fC437C43028d286AA625d36E as referrer (verified in the returned swap calldata). The “Swap on Stoa” button opens stoadex.com/trade?referrer=0x4e14…36E.
  • Code: open on GitHub (link set after publishing). Static site, no build step, no tracking, no keys. Full query details in README.md.
